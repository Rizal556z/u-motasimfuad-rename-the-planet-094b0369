Entry for the [Rename the Planet](https://make.fun/bounty/u-motasimfuad-rename-the-planet-094b0369) bounty on [make.fun](https://make.fun): one funny new name for a planet in our solar system, plus the why, in a single line under 200 characters.

## The entry

> Jupiter is now 'The Eternal Tantrum': it has thrown the same stormy fit for 300 years, and the fit is bigger than Earth.

Jupiter's Great Red Spot is a storm that has raged for centuries and is wider than Earth — a tantrum that never ends, and never fits anywhere else.

## Run

```sh
python3 main.py
```

Writes the entry line to `/output/entry.txt`. Pure Python standard library, no dependencies. The program validates the line first (1–200 characters, single line, not blank) and writes the exact same bytes on every run.
